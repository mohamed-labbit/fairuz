# First program

Save this UTF-8 text as `hello.fa`:

```fa
الاسم := "فيروز"
اكتب("مرحبا " + الاسم)
```

Run `./build/fairuz hello.fa`. Expected output:

```text
مرحبا فيروز
```

`:=` binds a name, `+` joins strings, and `اكتب` prints a value followed by a newline. Read the [tutorial](../tutorial/index.md) next.
