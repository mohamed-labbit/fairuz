# `قيم_مفصولة` — CSV

```fa
من قيم_مفصولة استورد CSV_حلل، CSV_رمز
صفوف := [["الاسم"، "ملاحظة"]، ["فيروز"، "فاصلة، واقتباس \""]]
نص := CSV_رمز(صفوف، "،")
تاكد(CSV_حلل(نص، "،") = صفوف)
```

## API and format

| Function | Behavior |
|---|---|
| `CSV_حلل(النص، الفاصل)` | Parse text into a list of rows, each a list of strings. |
| `CSV_رمز(الصفوف، الفاصل)` | Encode a list of nonempty row lists; convert each field using `سلسلة`. |

Both functions require a delimiter containing exactly one Unicode code point.
Comma, Arabic comma, semicolon, tab, and emoji delimiters are supported. Double
quote (`"`), CR, and LF are reserved and rejected, even for empty input.

The parser accepts LF, CRLF, and bare CR record endings. Inside a quoted field,
all of these remain part of the field unchanged. Two consecutive double quotes
inside a quoted field decode to one quote. A quote may only open at the start of
a field; after the closing quote only a delimiter, record ending, or end of input
is allowed. Whitespace is preserved, including unquoted leading/trailing spaces.
Rows may have different field counts; there is no automatic header handling.

The encoder separates records with LF and adds no final record terminator. It
quotes fields containing the delimiter, CR, LF, or a quote, and doubles embedded
quotes. A sole empty field is encoded as `""` so it cannot disappear at end of
input. Neither operation mutates its input lists.

## Empty input and failures

| Input | Result |
|---|---|
| `CSV_حلل(""، ",")` | `[]` |
| `CSV_حلل("\n"، ",")` | `[[""]]` |
| `CSV_حلل("a,\n"، ",")` | `[["a"، ""]]` — no extra row after the final newline |
| `CSV_رمز([]، ",")` | `""` |
| `CSV_رمز([[""]]، ",")` | Two quote characters |
| `CSV_رمز([[]]، ",")` | Runtime error: a row must contain at least one field |

Zero-field rows have no distinct representation in this format, so encoding them
fails instead of silently dropping them. Invalid delimiters, wrong container or
input types, unterminated quotes, quotes inside unquoted fields, and characters
(including spaces) after a closing quote also raise runtime errors. Source-level
exception recovery is unavailable.

For lists of nonempty string rows, decoding the encoded text preserves every
field and row. Other field types return as their string representation.

## Semantic tests

`stdlib/tests/اختبار_قيم_مفصولة.ف` covers empty records, mixed line endings,
quoted line endings, escaping, Unicode, whitespace, and 845 round trips across
five delimiters. Public CLI rejection cases in
`tests/test_stdlib/test_stdlib_e2e.cpp` check error messages, exit status, and
that execution stops after invalid input.
