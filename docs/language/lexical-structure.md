# Lexical structure

**Language behavior.** Source is decoded as UTF-8. Identifiers start with ASCII letters or `_`, or the Arabic letters accepted by `fairuz/fctype.hpp` (principally U+0621–U+063A and U+0641–U+064A). Continuations also admit ASCII digits, Arabic-Indic digits U+0660–U+0669, and tatweel U+0640. The table is selective rather than a general Unicode identifier rule. Keywords are matched by exact spelling; no Unicode normalization is performed by the lexer. `اسم` and `اسم_2` are valid examples; a diacritic in an identifier is rejected.

ASCII decimal digits, Arabic-Indic integer digits, `0b`, `0o`, and `0x` integer prefixes, and decimal forms with a dot are recognized. Underscores can occur in ASCII numeric token text. The lexer does not recognize exponent notation. Single and double quoted strings use `\\`, `\'`, `\"`, `\n`, `\r`, `\t`, `\b`, `\f`, `\/`, and four-hex-digit `\uXXXX`; raw newlines and surrogate escapes are rejected. `#` starts a comment through the end of a line.

Newlines separate statements. Parentheses, brackets, and braces suppress newline and indentation tokens inside them. A trailing backslash participates in line continuation. After `:`, a body can be one statement on the same logical line. If a logical newline follows the colon, the body requires increased indentation; dedents must match a previous level. Inline bodies do not add an indentation level. See [statements](statements.md) for clause alignment and examples. Mixed or inconsistent tab/space indentation is diagnosed. The lexer accepts CRLF by consuming `\r` and treating `\n` as the logical break. Both `,` and `،` (also `٬`) are comma tokens; `%` and `٪` are remainder tokens.

**Current implementation.** [Lexer](https://github.com/mohamed-labbit/fairuz/blob/86d706f83f9adc67cf2f4828a40dd6c11a3fb9b4/fairuz/flexer.cc) and [character table](https://github.com/mohamed-labbit/fairuz/blob/86d706f83f9adc67cf2f4828a40dd6c11a3fb9b4/fairuz/fctype.hpp) define the accepted character set. The table is limited to ASCII and selected U+06xx code points. See [unresolved behavior](../documentation/unresolved.md) for malformed UTF-8 and normalization questions.
