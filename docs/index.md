# Fairuz documentation

Fairuz (فيروز) is an Arabic-syntax language implemented in C++23. Source files are compiled to register bytecode and executed by a virtual machine. This documentation describes commit `86d706f83f9adc67cf2f4828a40dd6c11a3fb9b4` together with the working-tree source inspected on 30 September 2026. The working tree contained pre-existing uncommitted changes; see [coverage and verification](documentation/coverage.md) for the exact scope.
