# تشغيل البرامج

ينفذ `fairuz file.fa` ملفًا مصدريًا، ويمكن أيضًا استخدام `.ف` لملف الدخول. يُقبل ملف إدخال واحد فقط. يجوز وضع الخيارات قبل المسار أو بعده. لا يوجد مفسر تفاعلي أو تمرير لوسائط البرنامج من سطر الأوامر.

| الخيار | أثره |
|---|---|
| `--check` | التحليل والترجمة دون تنفيذ، ودون تنفيذ الاستيرادات. |
| `--dump-ast` | طباعة شجرة التحليل. |
| `--dump-bytecode` | طباعة التعليمات الوسيطة. |
| `--time` | طباعة زمن التنفيذ إلى مجرى الخطأ. |
| `--diagnostics=json` | إخراج التشخيصات المهيكلة إلى مجرى الخطأ. |
| `--semantic-tokens` | إخراج رموز دلالية؛ يقبل `-` للقراءة من الإدخال القياسي في هذا الوضع. |
| `-h` أو `--help`، و`-V` أو `--version` | عرض المساعدة أو رقم الإصدار. |

يعيد `fairuz format file.fa` تنسيق ملف صالح في مكانه. راجع [الأخطاء](../language/errors.md) و[تحميل الوحدات](../runtime/module-loading.md).
