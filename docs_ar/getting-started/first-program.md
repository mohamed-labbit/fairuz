# برنامجك الأول

احفظ النص التالي بترميز UTF-8 في ملف اسمه `hello.fa`:

```fa
الاسم := "فيروز"
اكتب("مرحبا " + الاسم)
```

نفّذ `./build/fairuz hello.fa`. الناتج المتوقع:

```text
مرحبا فيروز
```

يربط `:=` اسمًا بقيمة، ويصل `+` سلسلتين نصيتين، وتطبع `اكتب` القيمة وسطرًا جديدًا. انتقل بعدها إلى [الدروس](../tutorial/index.md).
