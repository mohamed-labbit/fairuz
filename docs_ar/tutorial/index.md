# دروس فيروز

كل مثال برنامج كامل. احفظ كل كتلة في ملف `.fa` بترميز UTF-8، ثم نفّذ `./build/fairuz file.fa`.

## ١. القيم والمتغيرات

الهدف: تعلّم الإسناد والحساب. يُستخدم `:=` للإسناد و`=` للمقارنة.

```fa
العدد := 7
العدد += 2
اكتب(العدد)
اكتب(العدد = 9)
```

السطران المتوقعان: `9` ثم `صحيح`. راجع [القيم والأنواع](../language/types-and-values.md) و[التعبيرات](../language/expressions.md).

## ٢. الشروط والحلقات

الهدف: تعلّم الكتل المزاحة، والتفرع، والتكرار على قائمة. تبدأ الكتلة بنقطتين رأسيتين؛ تُستخدم الإزاحة للتعليمات المتعددة، ويجوز وضع التعليمة الوحيدة في السطر نفسه. راجع [المتن في السطر نفسه](../language/statements.md).

```fa
المجموع := 0
لكل قيمة في [1، 2، 3]:
    المجموع += قيمة
اذا المجموع = 6:
    اكتب("تم")
غيره:
    اكتب("خطا")
```

الناتج المتوقع: `تم`. راجع [التعليمات](../language/statements.md).

## ٣. الدوال والمجموعات

الهدف: تعلّم الوسائط والقيم المعادة والقوائم والقواميس.

```fa
دالة ضعف(قيمة):
    ارجع قيمة * 2

نتائج := [ضعف(2)، ضعف(3)]
سجل := {"اول": نتائج[0]}
اكتب(سجل["اول"])
```

الناتج المتوقع: `4`. راجع [الدوال](../language/functions.md) و[القيم](../language/types-and-values.md).

## ٤. الاستيراد والأخطاء

الهدف: استخدام دالة مستوردة وتوكيد. ينفّذ الاستيراد الوحدة عند الوصول إليه أثناء التشغيل.

```fa
من رياضيات استورد عاملي
القيمة := عاملي(5)
تاكد القيمة = 120
اكتب(القيمة)
```

الناتج المتوقع: `120`. راجع [الاستيراد](../language/modules-and-imports.md) و[الأخطاء](../language/errors.md).
