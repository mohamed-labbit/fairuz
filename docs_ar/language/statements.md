# التعليمات

يقبل الرأس المنتهي بـ`:` تعليمة واحدة في السطر المنطقي نفسه، أو متنًا غير فارغ في الأسطر التالية مع زيادة الإزاحة. ينطبق ذلك على `اذا` و`غيره اذا` و`غيره` و`طالما` و`لكل` والدوال والطرائق. ويقبل الصنف طريقة واحدة في السطر نفسه؛ راجع [الدوال والأصناف](functions.md). يوضح [وصف القواعد](grammar.ebnf) هذه الصيغ.

| الصيغة | الأثر |
|---|---|
| `اسم := تعبير` | ربط اسم أو تغيير قيمته؛ ويجوز إسناد فهرس أو حقل. |
| `اذا شرط: ... غيره: ...` | تنفيذ إحدى الكتلتين بحسب الصدق؛ وتضيف `غيره اذا` فرعًا. |
| `طالما شرط: ...` | إعادة اختبار الشرط قبل كل دورة. |
| `لكل اسم في تعبير: ...` | تقييم القائمة والتكرار على عناصرها. |
| `اخرج`، `اكمل` | الخروج من الحلقة الداخلية أو بدء دورتها التالية. |
| `ارجع تعبير` | مغادرة الدالة بقيمة؛ وتعيد `ارجع` المجردة `عدم`. |
| `تاكد شرط، رسالة` | استدعاء دالة التوكيد؛ والرسالة اختيارية. |
| `استورد`، `من ... استورد ...` | تحميل وحدة أو ربط أسماء منها. |

يؤدي استعمال `اخرج` أو `اكمل` خارج حلقة، أو `ارجع` خارج دالة، إلى خطأ ترجمة. راجع [الاستيراد](modules-and-imports.md) و[الأخطاء](errors.md). كائنات المكررات المكتبية تستخدم البروتوكول الصريح `التالي()`؛ أما `لكل` الأصلية فتجتاز القوائم حاليًا.

## المتن في السطر نفسه

اكتب تعليمة المتن الوحيدة بعد النقطتين. يبدأ كل فرع `غيره اذا` أو `غيره` في سطر مستقل، وبالإزاحة نفسها لرأس `اذا` الأصلي.

```fa
المجموع := 0
لكل قيمة في [1، 2، 3]: المجموع += قيمة
اذا المجموع < 0: اكتب("سالب")
غيره اذا المجموع = 6: اكتب("تم")
غيره: اكتب("غير متوقع")
طالما المجموع < 8: المجموع += 1
اكتب(المجموع)
```

الناتج: `تم` ثم `8`. التعليمة التالية التي لها إزاحة الرأس نفسه تقع خارج المتن.

يمكن الجمع بين المتن في السطر نفسه والمتن المزاح في سلسلة شرطية واحدة. تقبل هذه الصيغة `ارجع` و`اخرج` و`اكمل` والتوكيدات والاستدعاءات والإسنادات، مع بقاء قيود استعمالها داخل الدوال والحلقات.

```fa
دالة اشارة(قيمة):
    اذا قيمة < 0: ارجع -1
    غيره اذا قيمة = 0:
        ارجع 0
    غيره: ارجع 1
تاكد اشارة(-5) = -1
تاكد اشارة(0) = 0
تاكد اشارة(5) = 1

لكل قيمة في [1، 2، 3، 4]:
    اذا قيمة = 2: اكمل
    اذا قيمة = 4: اخرج
    اكتب(قيمة)
```

الناتج: `1` ثم `3`. لا يمنع الإرجاع من فرع تنفيذ الفروع الأخرى عندما تتحقق شروطها.

يجوز أن تكون تعليمة المتن نفسها تعليمة مركبة. في المثال التالي، يتبع `غيره` شرط `اذا` الخارجي لأنه يحاذيه:

```fa
قيمة := 0
اذا خطا: اذا صحيح: قيمة := 1
غيره: قيمة := 2
اكتب(قيمة)
```

الناتج: `2`. استخدم المتن المزاح عندما يصعّب التداخل قراءة البنية.

## حدود الصيغة

- يستلزم السطر الجديد المنطقي بعد `:` متنًا مزاحًا. لا يُعد التعليق بعد النقطتين متنًا.
- تجوز الأسطر الفارغة والتعليقات بين التعليمات أو الطرائق، لكن لا يكفي متن مكوّن من تعليقات فقط.
- يحتوي المتن في السطر نفسه تعليمة واحدة. لا تُقبل تعليمات متجاورة أو مفصولة بفواصل منقوطة في السطر نفسه.
- لا تنشئ هذه الصيغة مستوى إزاحة يحتاج إلى إغلاق؛ وأي تقليل لاحق للإزاحة يغلق متنًا مزاحًا محيطًا. يجوز أن تنتهي التعليمة الأخيرة عند نهاية الملف، حتى `ارجع` المجردة داخل دالة.
- يمكن أن تمتد الاستدعاءات والمجموعات المحاطة بأقواس عبر أسطر فعلية؛ راجع [الأسطر المنطقية](lexical-structure.md).

مثلًا، الصيغتان التاليتان غير صالحتين:

```text
اذا صحيح:
اكتب(1)

دالة مثال(): ارجع 1 ارجع 2
```
