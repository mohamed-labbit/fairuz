# البنية المعجمية

**سلوك اللغة.** يُقرأ المصدر بترميز UTF-8. يبدأ المعرّف بحرف لاتيني ASCII أو `_`، أو بأحد الحروف العربية التي يقبلها جدول `fairuz/fctype.hpp`، وأهمها U+0621–U+063A وU+0641–U+064A. ويمكن أن يتبعها رقم لاتيني، أو رقم عربي هندي U+0660–U+0669، أو تطويل U+0640. ليست هذه قاعدة عامة لكل حروف Unicode. تُطابَق الكلمات المحجوزة حرفيًا؛ ولا يطبّع المحلل النص وفق Unicode. `اسم` و`اسم_2` مثالان صالحان، أما علامة التشكيل داخل المعرّف فتُرفض.

تُعرف الأعداد الصحيحة العشرية اللاتينية والعربية الهندية، والبادئات `0b` و`0o` و`0x`، والأعداد الحقيقية ذات النقطة. قد تظهر `_` داخل نص العدد المكتوب بالأرقام اللاتينية. لا يدعم المحلل كتابة الأس بالصورة `1e3`. تُكتب السلاسل بعلامة اقتباس مفردة أو مزدوجة. تسلسلات الهروب المقبولة هي `\\` و`\'` و`\"` و`\n` و`\r` و`\t` و`\b` و`\f` و`\/` و`\uXXXX`، حيث `XXXX` أربع خانات سداسية عشرية. يُرفض السطر الجديد المباشر داخل السلسلة ورمز Unicode البديل في `\u`.

يبدأ `#` تعليقًا حتى نهاية السطر. يفصل السطر الجديد المنطقي بين التعليمات، إلا داخل `()` أو `[]` أو `{}`. تشارك الشرطة المائلة العكسية الأخيرة في وصل السطر. يمكن وضع تعليمة المتن الوحيدة بعد `:` في السطر المنطقي نفسه. أما إذا تلا النقطتين سطر جديد منطقي، فتجب زيادة إزاحة المتن، ويجب أن يطابق تقليل الإزاحة مستوى سابقًا. لا يضيف المتن في السطر نفسه مستوى إزاحة. راجع [التعليمات](statements.md) لمحاذاة الفروع والأمثلة. يُشخَّص الخلط غير المتسق بين المسافات والجدولات. يعامل المحلل `\r\n` سطرًا منطقيًا واحدًا. تقبل الفاصلة `,` أو `،` أو `٬`، ويقبل عامل الباقي `%` أو `٪`.

**تفصيل التنفيذ الحالي.** يحدد [المحلل المعجمي](https://github.com/mohamed-labbit/fairuz/blob/86d706f83f9adc67cf2f4828a40dd6c11a3fb9b4/fairuz/flexer.cc) و[جدول المحارف](https://github.com/mohamed-labbit/fairuz/blob/86d706f83f9adc67cf2f4828a40dd6c11a3fb9b4/fairuz/fctype.hpp) مجموعة المحارف المقبولة. راجع [المسائل غير المحسومة](../documentation/unresolved.md) بشأن UTF-8 غير الصالح والتطبيع.
