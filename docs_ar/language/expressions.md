# التعبيرات والإسناد

تُقيَّم المعاملات ووسائط الاستدعاء بترتيب ورودها في المصدر. يختصر العاملان `و` و`او` تقييم الطرف الأيمن عندما يحدد الأيسر النتيجة. تُقيَّم الدالة المستدعاة ثم الوسائط الموضعية. لا توجد وسائط مسماة أو قيم افتراضية. الإسناد في مستوى التعليمة، ويُرفض داخل تعبير آخر.

| من الأقوى ربطًا إلى الأضعف | العوامل | اتجاه التجميع |
|---|---|---|
| اللاحقة | `(...)`، `[...]`، `.name` | يسار |
| الأس | `**` | يمين |
| الأحادية | `+`، `-`، `~`، `ليس` | يمين |
| الضرب | `*`، `/`، `%`، `٪` | يسار |
| الجمع | `+`، `-` | يسار |
| الإزاحة الثنائية | `<<`، `>>` | يسار |
| الترتيب | `<`، `<=`، `>`، `>=` | يسار، بلا دلالة مقارنة متسلسلة |
| المساواة | `=`، `!=` | يسار |
| البتات | `&`، `^`، `\|` | يسار |
| المنطق | `و`، `او` | يسار |

ترتيب `&` ثم `^` ثم `|` هو ترتيب القوة الموضح. يحيط العامل الأحادي بعملية الأس من يسارها: `-2 ** 2` تعني `-(2 ** 2)`، وتُقبل `2 ** -2`. تغيّر الأقواس الأولوية. المقارنات عمليات ثنائية؛ لا تعتمد على `1 < 2 < 3` كمقارنة رياضية متسلسلة.

يسند `:=` إلى اسم أو فهرس أو حقل. يتجمع `a := b := 3` من اليمين. تقرأ معاملات `+=` و`-=` و`*=` و`/=` و`%=` و`&=` و`|=` و`^=` و`<<=` و`>>=` القيمة، ثم تجري العملية، ثم تكتب الناتج. ينسخ المحلل شجرة الهدف لقراءته؛ لذلك قد تُقيَّم أجزاء هدف مفهرس ذي آثار جانبية أكثر من مرة. راجع [المسائل المفتوحة](../documentation/unresolved.md). يُرفض هدف مثل `1 := 2` أثناء التحليل.

تتطلب العمليات العددية أنواعًا مدعومة، وتتطلب عمليات البتات والإزاحة أعدادًا صحيحة. يصل `+` أيضًا سلاسل أو قوائم. يقرأ `[]` من القوائم والسلاسل والقواميس؛ ويجب أن يكون فهرس القائمة أو السلسلة صحيحًا، ويُرفع خطأ عند تجاوز الحدود. يمكن الإسناد إلى عنصر قائمة، لا إلى عنصر سلسلة. توفر الدالة المدمجة [`مقطع`](../standard-library/builtins.md) الاقتصاص؛ لا توجد صياغة `a[1:3]`. راجع [سلوك الأعداد](../runtime/numeric-behavior.md).

```fa
اكتب(2 + 3 * 4)
اكتب(2 ** -2)
```

الناتج المتوقع: `14` ثم `0.25`.
