# القيم والأنواع

| الصياغة | القيمة | ملاحظة |
|---|---|---|
| `عدم` | قيمة خالية | يطبعها مسار تحويل داخلي `nil`؛ وتطبعها `اكتب` باسم `عدم`. |
| `صحيح`، `خطا` | منطقيتان | منفصلتان عن الأعداد. |
| `42`، `0b101`، `0o12`، `0x2a`، `٤٢` | صحيح | يمكن أن يتجاوز حجم كلمة الآلة. |
| `3.5` | حقيقي | يمثَّل حاليًا بعدد مزدوج الدقة. |
| `"نص"`، `'text'` | سلسلة | نص UTF-8؛ يحسب الفهرس نقاط Unicode. |
| `[1، 2]`، `(1، 2)`، `()` | قائمة | الصياغة بين قوسين مع فاصلة تنشئ قائمة، لا صفًا. |
| `{"ا": 1}` | قاموس | المفاتيح والقيم تعبيرات. |

الدوال والأصناف والنسخ والوحدات والدوال الأصلية ومقابض الملفات قيم وقت تشغيل أيضًا. القوائم والقواميس كائنات مرجعية قابلة للتغيير؛ إسنادها إلى اسم ثانٍ لا ينسخها. السلاسل غير قابلة للتغيير. تستخدم مفاتيح القواميس مساواةً وبصمةً تختلفان عن المقارنة العميقة للقوائم والقواميس؛ استخدم مفاتيح بسيطة للحصول على سلوك متوقع.

**سلوك اللغة.** القيم الكاذبة هي `عدم` و`خطا` والصفر العددي. كل كائن صادق، حتى السلسلة أو القائمة أو القاموس الفارغ. يقارن `=` و`!=` الأعداد بالقيمة والسلاسل بالمحتوى، ويقارنان القوائم والقواميس تكراريًا مع معالجة الدورات. لا تتساوى دالتان أو صنفان أو نسختان أو وحدتان أو موردان مختلفان، إلا عند الإشارة إلى الكائن نفسه. راجع [التعبيرات](expressions.md) و[الأعداد](../runtime/numeric-behavior.md).
