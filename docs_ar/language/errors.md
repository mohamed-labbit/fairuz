# الأخطاء والتشخيصات

تمنع الأخطاء المعجمية والنحوية، مثل الإزاحة غير الصالحة أو الهروب الخاطئ أو القوس الناقص أو `1 := 2`، نجاح الترجمة. قد يتعافى المحلل بما يكفي للإبلاغ عن أخطاء تركيب متعددة، لكن البرنامج لا يصبح قابلًا للتنفيذ. يرفض المترجم `ارجع` خارج الدالة وتعليمات التحكم بالحلقة خارج الحلقة. تشمل أخطاء التشغيل الاسم أو الوحدة المفقودين، وعدد الوسائط أو أنواعها غير الصحيحة، والفهرس غير الصالح، والقسمة على صفر.

تقيّم `تاكد شرط` أو `تاكد شرط، رسالة` التوكيد؛ ويرفع الشرط الكاذب خطأ تشغيل. ترفع `عطل(رسالة)` خطأ مباشرة. لا توجد صياغة `try` أو `catch` في المحلل المصدري، ولذلك لا يستطيع البرنامج عادةً التعافي من خطأ تشغيل. تُكتب التشخيصات إلى مجرى الخطأ، ويختار `--diagnostics=json` شكلًا مهيكلًا. النص الحرفي لرسالة الخطأ ليس واجهة ثابتة موثقة.

```fa
تاكد 2 + 2 = 4
اكتب("ok")
```

الناتج المتوقع: `ok`. راجع [تشغيل البرامج](../getting-started/running-programs.md).
