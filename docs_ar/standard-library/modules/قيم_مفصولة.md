# `قيم_مفصولة` — CSV

```fa
من قيم_مفصولة استورد CSV_حلل، CSV_رمز
صفوف := [["الاسم"، "ملاحظة"]، ["فيروز"، "فاصلة، واقتباس \""]]
نص := CSV_رمز(صفوف، "،")
تاكد(CSV_حلل(نص، "،") = صفوف)
```

## الواجهة والتنسيق

| الدالة | السلوك |
|---|---|
| `CSV_حلل(النص، الفاصل)` | يحلل نصاً إلى قائمة صفوف؛ كل صف قائمة سلاسل. |
| `CSV_رمز(الصفوف، الفاصل)` | يرمز قائمة صفوف غير خالية من الحقول، ويحول كل حقل بواسطة `سلسلة`. |

يجب أن يكون الفاصل نصاً من نقطة ترميز Unicode واحدة. يمكن استخدام الفاصلة
العربية أو اللاتينية أو الفاصلة المنقوطة أو الجدولة أو رمز تعبيري. الاقتباس
المزدوج وCR وLF محارف محجوزة؛ ترفضها الدالتان حتى مع مدخل فارغ.

يقبل المحلل LF وCRLF وCR المفرد لإنهاء السجلات، ويحفظها كما هي داخل الحقول
المقتبسة. اقتباسان متجاوران داخل حقل مقتبس يمثلان اقتباساً واحداً. لا يفتح
الاقتباس إلا في بداية الحقل، ولا يسمح بعد إغلاقه إلا بفاصل أو نهاية سجل أو
نهاية النص. تبقى المسافات، بما فيها المحيطة بالحقل غير المقتبس، دون تغيير.
يمكن اختلاف عدد الحقول بين الصفوف؛ لا توجد معالجة خاصة لصف العناوين.

يفصل الكاتب السجلات بـLF دون نهاية سجل إضافية في آخر النص. يقتبس الحقول التي
تحتوي الفاصل أو CR أو LF أو اقتباساً، ويضاعف الاقتباسات الداخلية. يكتب الحقل
الفارغ الوحيد كاقتباسين حتى لا يختفي عند نهاية الملف. لا يعدل قوائم الإدخال.

## الفراغ والأخطاء

| المدخل | النتيجة |
|---|---|
| `CSV_حلل(""، ",")` | `[]` |
| `CSV_حلل("\n"، ",")` | `[[""]]` |
| `CSV_حلل("a,\n"، ",")` | `[["a"، ""]]` دون صف إضافي |
| `CSV_رمز([]، ",")` | `""` |
| `CSV_رمز([[""]]، ",")` | علامتا اقتباس |
| `CSV_رمز([[]]، ",")` | خطأ وقت تشغيل: يجب أن يحوي الصف حقلاً واحداً على الأقل |

لا يملك الصف الخالي من الحقول تمثيلاً مميزاً، لذا يرفضه الكاتب بدلاً من إسقاطه.
يرفع التنفيذ أيضاً خطأ وقت تشغيل عند نوع مدخل غير صالح، أو فاصل غير صالح، أو
اقتباس غير مغلق، أو اقتباس داخل حقل غير مقتبس، أو محارف بعد إغلاق الاقتباس
حتى إن كانت مسافات. لا توفر اللغة التقاط هذه الأخطاء في المصدر.

تحفظ دورة الترميز ثم التحليل كل الحقول والصفوف لقوائم الصفوف النصية غير
الخالية من الحقول. أما الأنواع الأخرى فتعاد بصورتها النصية.
