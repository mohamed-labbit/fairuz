**تفصيل التنفيذ الحالي.** تسرد الصفحة التصريحات الموجودة في الملف؛ لا تضمن عمل كل تبعية أو دالة أصلية. الاستدعاء يستخدم وسائط موضعية، وينتقل خطأ الدالة المستدعاة إلى المستدعي لأن اللغة لا توفر التقاط الاستثناءات. الترميز `Class.method(...)` في الجدول توضيحي لطريقة داخل صنف.
