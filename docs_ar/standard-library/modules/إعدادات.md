# `إعدادات` — إعدادات INI

```fa
من إعدادات استورد اعدادات_INI
اعدادات := اعدادات_INI().حلل("timeout=30\n[server]\nurl: https://host/?a=b\n")
تاكد(اعدادات.خذ("server"، "timeout"، عدم) = "30")
تاكد(اعدادات.خذ("server"، "url"، عدم) = "https://host/?a=b")
نسخة := اعدادات_INI().حلل(اعدادات.نص())
تاكد(نسخة.نص() = اعدادات.نص())
```

## الواجهة

| العملية | السلوك |
|---|---|
| `اعدادات_INI()` | ينشئ إعدادات تحوي القسم الفارغ `default`. |
| `.حلل(النص)` | يدمج القيم في الكائن ويعيده؛ يبدأ كل استدعاء من `default`. |
| `.اقسام()` | يعيد أسماء الأقسام ومنها `default` دون ضمان ترتيبها. |
| `.خذ(القسم، المفتاح، البديل)` | يبحث في القسم الموجود ثم `default` ثم يعيد البديل؛ إذا غاب القسم يعيد البديل مباشرة. |
| `.ضع(القسم، المفتاح، القيمة)` | يتحقق من الأسماء وينشئ القسم عند الحاجة ويخزن `سلسلة(القيمة)` ثم يعيد الكائن. |
| `.نص()` | يكتب نصاً بترتيب ثابت، أو يرفع خطأ إن تعذر حفظ قيمة عند إعادة القراءة. |
| `اقرا_INI(المسار)` | يعيد نتيجة نجاح تحوي الإعدادات، أو نتيجة فشل إذا تعذرت قراءة الملف؛ أخطاء الصياغة تنتقل كأخطاء وقت تشغيل. |

## قواعد التحليل

تنتهي الأسطر بـLF أو CRLF. تهمل الأسطر الفارغة والتعليقات التي تبدأ، بعد قص
المسافات، بـ`#` أو `;`. تقص المسافات المحيطة بأسماء الأقسام والمفاتيح والقيم.
الأسماء حساسة لحالة الأحرف. يختار `[default]` القسم الافتراضي صراحة، وتحفظ
الأقسام المسماة الفارغة.

**أول** `=` أو `:` يفصل المفتاح عن القيمة؛ تبقى الفواصل التالية ضمن القيمة.
لذلك يحفظ `url: https://host/?a=b` العنوان كاملاً. يسمح بالقيم الفارغة، وتبقى
`#` و`;` داخل القيمة محارف حرفية. تدمج الأقسام المتكررة وتغلب آخر قيمة للمفتاح.
لا يمسح التحليل الإعدادات السابقة ولا يتراجع عن التعديلات إذا ظهر خطأ لاحق.

اسم القسم غير فارغ ولا يحتوي أقواساً مربعة أو CR أو LF. المفتاح غير فارغ ولا
يحتوي `=` أو `:` أو CR أو LF، ولا يبدأ بـ`[` أو `#` أو `;`. الأسماء الممررة
إلى `ضع` لا يجوز أن تحيط بها مسافات. ترفع العناوين المشوهة والأسماء غير الصالحة
والأسطر التي لا تحوي فاصلاً أخطاء وقت تشغيل.

## الترميز وحفظ المعنى

تكتب القيم الافتراضية قبل الأقسام المسماة دائماً، فلا تنتقل خطأً إلى قسم سابق.
ترتب الأقسام المسماة ومفاتيح كل قسم وفق ترتيب السلاسل في اللغة. يستخدم الناتج
`key = value` ونهايات LF، ويحفظ الأقسام المسماة الفارغة. لا يحفظ التعليقات أو
التنسيق الأصلي. يرمز الكائن الفارغ بالكامل إلى نص فارغ.

لا يدعم هذا التنسيق الاقتباس أو الاستيفاء أو الهروب أو القيم متعددة الأسطر.
يمكن لـ`.ضع(...)` تخزين قيمة متعددة الأسطر أو محاطة بمسافات في الذاكرة، لكن
`.نص()` يرفضها بدلاً من فقد جزء منها عند إعادة التحليل. يسمح بالنص الفارغ
والمسافات الداخلية. للإعدادات القابلة للتمثيل، تحفظ إعادة القراءة القيم
وانتماءها للأقسام والبحث في الافتراضي؛ وينتج الترميز التالي النص نفسه.

## الاختبارات الدلالية

يتحقق `stdlib/tests/اختبار_إعدادات.ف` من أسبقية الفاصل والمفاتيح المتكررة
والدمج والافتراضي والقيم والأقسام الفارغة وUnicode وثبات الناتج ودورة الترميز.
وتتحقق اختبارات `tests/test_stdlib/test_stdlib_e2e.cpp` من رفض الصياغة والأسماء
غير الصالحة والقيم التي لا يمكن حفظها، بما يشمل رمز الخروج والتشخيص.
