# الدوال المدمجة

تتوفر الأسماء الآتية دون استيراد. يعرض التوقيع مواضع الوسائط، وتشير `...` إلى عدد متغير منها. قد تعيد بعض الدوال `عدم` عند النوع الخاطئ، بينما ترفع أخرى خطأً، كما يوضح الجدول. تُسجَّل في [fbuiltins.cc](https://github.com/mohamed-labbit/fairuz/blob/86d706f83f9adc67cf2f4828a40dd6c11a3fb9b4/fairuz/fbuiltins.cc). الأسماء التي تبدأ بـ`__` في سجلها وصلات داخلية للمكتبة، وليست واجهة عامة.

| التوقيع | الناتج والآثار | المدخلات غير الصالحة والحواف |
|---|---|---|
| `طول(قيمة)` | طول سلسلة بنقاط Unicode، أو قائمة، أو قاموس، بوصفه صحيحًا. | يعيد `عدم` للأنواع الأخرى؛ ويحسب بايتات السلسلة غير الصالحة UTF-8. |
| `اضف(قائمة، قيمة، ...)` | يضيف القيم إلى القائمة نفسها، ويعيد `عدم`. | يرفع خطأ عند نقص الوسائط أو كون الأول غير قائمة. |
| `احذف(قائمة)` | يحذف آخر عنصر ويعيد القائمة. | يرفع خطأ للقائمة الفارغة أو النوع الخاطئ. |
| `مقطع(قيمة، بداية، نهاية)` | ينشئ سلسلة أو قائمة جديدة؛ **النهاية مشمولة**، ويجوز حذفها. | يحتاج فهارس صحيحة غير سالبة؛ والتجاوز يرفع خطأ. |
| `قائمة(قيمة، ...)` | ينشئ قائمة جديدة من الوسائط، أو قائمة فارغة بلا وسائط. | تُخزَّن القيم المرجعية دون نسخ عميق. |
| `قاموس(مفتاح، قيمة، ...)` | ينشئ قاموسًا من أزواج الوسائط المتعاقبة. | يتجاهل التنفيذ الحالي الوسيط الأخير إذا لم يكن له زوج. |
| `اكتب(قيمة، ...)` | يطبع الوسائط وبينها جدولات ثم سطرًا جديدًا؛ ويعيد `صحيح`. | بلا وسائط يطبع سطرًا فارغًا؛ وتظهر الدورة باسم `<cycle>`. |
| `ادخل()` | يقرأ سطرًا من الإدخال القياسي كسلسلة. | يعيد `عدم` عند نهاية الإدخال. |
| `افتح(مسار، وضع)` | يفتح مقبض ملف. | تنتقل أخطاء المسار والوضع والملف. |
| `اضف_ملف(ملف، نص)` | يكتب إلى مقبض مفتوح. | يرفع خطأ للمقبض أو النوع الخاطئ أو فشل الإدخال/الإخراج. |
| `اغلق(ملف)` | يغلق مقبض ملف. | المقبض غير الصالح يرفع خطأ. |
| `صنف(قيمة)` | يعيد سلسلة عربية باسم نوع القيمة. | يتطلب وسيطًا واحدًا. |
| `طبيعي(قيمة)` | يعيد الصحيح نفسه أو يحول حقيقيًا إلى صحيح. | يعيد `عدم` للأنواع الأخرى؛ وقد تفشل القيم غير المنتهية أو الخارجة عن المدى. |
| `حقيقي(قيمة)` | يحول عددًا إلى حقيقي. | يعيد `عدم` للأنواع الأخرى؛ وقد يفقد الصحيح الكبير دقته. |
| `سلسلة()` أو `سلسلة(قيمة)` | ينشئ سلسلة؛ بلا وسيط ينتج `""`، ومع وسيط يصيّر القيمة نصيًا. | أكثر من وسيط يرفع خطأ. |
| `منطقي(قيمة)` | يعيد نتيجة اختبار الصدق. | العدد الخاطئ من الوسائط يرفع خطأ. |
| `اقسم(نص، فاصل)` | يعيد قائمة أجزاء عند فاصل مطابق لبايتات النص. | غير السلاسل تعيد `عدم`؛ والفاصل الفارغ يعيد قائمة بعنصر واحد. |
| `اجمع(قائمة، فاصل)` | يصل التمثيل النصي لعناصر القائمة بسلسلة فاصلة. | النوع الخاطئ يعيد `عدم`. |
| `جزء(نص، بداية، نهاية)` | يقتطع سلسلة؛ **النهاية غير مشمولة**، والمواضع بنقاط Unicode. | العدد أو النوع الخاطئ أو المجال السالب يرفع خطأ. |
| `يحتوي(نص، جزء)` | اختبار احتواء سلسلة فرعية. | غير السلاسل تعيد `عدم`؛ والنص المطلوب الفارغ صحيح دائمًا. |
| `قص(نص)` | ينشئ سلسلة بعد حذف الفراغ والجدولة وCR وLF من الطرفين. | غير السلسلة تعيد `عدم`. |
| `ادنى(رقم)`، `اعلى(رقم)` | تقريب إلى الأسفل أو الأعلى. | يتطلبان عددًا. |
| `تقريب(رقم)` | قيمة عددية مقرّبة. | يتطلب عددًا. |
| `مطلق(رقم)` | القيمة المطلقة. | يتطلب عددًا. |
| `اصغر(رقم، ...)`، `اكبر(رقم، ...)` | أصغر الوسائط أو أكبرها. | قد يفشل الإدخال الفارغ أو القيم غير القابلة للمقارنة. |
| `قوة(أساس، أس)` | حساب الأس مثل `**`. | يتطلب أعدادًا؛ الأس الصحيح السالب ينتج حقيقيًا. |
| `جذر(رقم)` | الجذر التربيعي كحقيقي. | يتبع النوع أو المجال غير الصالح معالجة الخطأ الأصلية. |
| `تاكد(شرط)` أو `تاكد(شرط، رسالة)` | يمرّ الشرط الصادق، ويرفع الكاذب خطأ توكيد. | عدد الوسائط الآخر يفشل. |
| `عطل(رسالة)` | يرفع خطأ تشغيل. | لا توجد صياغة مصدرية لالتقاطه. |
| `ساعة()` | قيمة ساعة العملية. | الدقة تعتمد على المنصة. |
| `وقت()` | يعيد `عدم` حاليًا؛ لا يوجد عقد لزمن الساعة الجدارية. | راجع [المسائل المفتوحة](../documentation/unresolved.md). |

```fa
القيم := قائمة(1، 2)
اضف(القيم، 3)
تاكد طول(القيم) = 3
اكتب(جزء("فيروز"، 0، 2))
```

الناتج المتوقع: `في`. تُعرض الدوال المستوردة في [فهرس الوحدات](index.md). اختبر حدود الملفات والأعداد على المنصة المستهدفة قبل الاعتماد عليها.
