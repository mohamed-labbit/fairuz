# تحميل الوحدات

يُحل الاسم `اسم` إلى `اسم.ف`، ويُحل `حساب.ادوات` إلى `حساب/ادوات.ف`. يبحث المحمّل الحالي بالترتيب في: مجلد `FAIRUZ_STDLIB` إن ضُبط؛ ومجلد المكتبة القياسية في شجرة المصدر المسجّل وقت البناء؛ ومجلد التثبيت المسجّل وقت الإعداد؛ ثم مجلد الملف المستورِد؛ ثم مجلد العمل الحالي. لذلك قد تتقدم وحدة مضمنة على ملف محلي يحمل الاسم نفسه.

تُحمَّل الوحدة مرة واحدة لكل مسار محلول داخل الآلة الافتراضية، ولها بيئة عامة مستقلة. تبدأ التهيئة عند تعليمة الاستيراد، لا عند التحليل. تحتفظ الدوال المستوردة ببيئة وحدتها الأصلية. يؤدي فشل إيجاد وحدة أو اسم إلى خطأ تشغيل. لم يُحدَّد سلوك الاستيراد الدوري بوصفه عقدًا مستقرًا؛ راجع [المسائل غير المحسومة](../documentation/unresolved.md).

**تفصيل التنفيذ الحالي.** توجد آليات البحث والتخزين والتنفيذ في [fvm.cc](https://github.com/mohamed-labbit/fairuz/blob/86d706f83f9adc67cf2f4828a40dd6c11a3fb9b4/fairuz/fvm.cc). إذا نُقل التثبيت، عيّن `FAIRUZ_STDLIB` صراحةً.
