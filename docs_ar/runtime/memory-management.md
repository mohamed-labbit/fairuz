# الذاكرة والمراجع والتغيير

القوائم والقواميس والنسخ والوحدات وغيرها من الكائنات قيم مرجعية. إسناد كائن قابل للتغيير إلى اسم آخر لا ينسخه:

```fa
ا := [1]
ب := ا
اضف(ب، 2)
اكتب(طول(ا))
```

الناتج المتوقع: `2`. استخدم دالة نسخ مثل `مجموعات.انسخ_قائمة` إذا احتجت قائمة مستقلة. السلاسل غير قابلة للتغيير. قد تحتوي المجموعات المتداخلة على دورات؛ ويعالج التنفيذ الحالي هذه الدورات عند المقارنة والطباعة.

**تفصيل التنفيذ الحالي.** يدير [fgc.cc](https://github.com/mohamed-labbit/fairuz/blob/86d706f83f9adc67cf2f4828a40dd6c11a3fb9b4/fairuz/fgc.cc) جمعًا للقمامة بطريقة التمييز والإزالة، متتبعًا الجذور من حالة الآلة والكائنات. يعرّف [fobj_header.hpp](https://github.com/mohamed-labbit/fairuz/blob/86d706f83f9adc67cf2f4828a40dd6c11a3fb9b4/fairuz/fobj_header.hpp) رؤوس الكائنات. توقيت الجمع وتخطيط الذاكرة وعناوين الكائنات تفاصيل داخلية. لا توجد صياغة مصدرية لإتلاف الكائن أو تحريره يدويًا.
