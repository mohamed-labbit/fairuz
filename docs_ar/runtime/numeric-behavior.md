# سلوك الأعداد

تتوسع الأعداد الصحيحة إلى كائنات كبيرة عند الحاجة في الحساب والعمليات الثنائية والإزاحات والأسس الصحيحة غير السالبة. قد ترفض دالة أصلية تتطلب فهرسًا أو عددًا بحجم الآلة عددًا كبيرًا، رغم قبول العمليات الحسابية له. تستخدم الأعداد الحقيقية حاليًا تمثيلًا مزدوج الدقة. قد يحوّل الحساب المختلط الصحيح إلى حقيقي، وقد يفقد الصحيح الكبير دقته أثناء التحويل.

| العملية | السلوك المرصود |
|---|---|
| `6 / 3` | الصحيح `2` لأن القسمة تامة. |
| `7 / 2` | الحقيقي `3.5` لأن القسمة غير تامة. |
| `-7 % 3` | الباقي `-1`؛ إشارته تتبع المقسوم. |
| `2 ** 100` | صحيح كبير بلا حد كلمة آلة ثابت. |
| `2 ** -2` | الحقيقي `0.25`. |
| `x / 0` أو `x % 0` | خطأ تشغيل. |
| `<<`، `>>`، `&`، `\|`، `^`، `~` | عمليات صحيحة؛ الأنواع أو مقادير الإزاحة غير الصالحة تفشل. |

تجري `طبيعي` و`حقيقي` و`سلسلة` تحويلات صريحة؛ وتُشرح أنواع المدخلات والفشل في [الدوال المدمجة](../standard-library/builtins.md). ترث العمليات الحقيقية محدودية الدقة والقيم غير المنتهية من التنفيذ مزدوج الدقة الحالي. ليست صياغة رسائل الخطأ ولا جميع أطراف مكتبة الرياضيات في المنصة ضمانًا. راجع [المسائل غير المحسومة](../documentation/unresolved.md).

**تفصيل التنفيذ الحالي.** يعالج [finteger.cc](https://github.com/mohamed-labbit/fairuz/blob/86d706f83f9adc67cf2f4828a40dd6c11a3fb9b4/fairuz/finteger.cc) الصحيحات الكبيرة، ويختار [fvm.cc](https://github.com/mohamed-labbit/fairuz/blob/86d706f83f9adc67cf2f4828a40dd6c11a3fb9b4/fairuz/fvm.cc) العملية المناسبة.
