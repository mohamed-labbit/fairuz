# صيانة التوثيق

حدّث التوثيق وفق التنفيذ الفعلي، لا بالقياس على لغة أخرى. افحص الرموز المعجمية وفروع المحلل والمترجم والآلة الافتراضية وسجل الدوال المدمجة وملفات المكتبة والاختبارات. ميّز بين **سلوك اللغة** و**تفصيل التنفيذ الحالي** و**أمر غير محسوم** حيث يلزم. أبقِ صياغة فيروز وأسماءها كما هي، واحفظ أمثلتها بترميز UTF-8 دون محارف اتجاه خفية.

بعد تغيير ملفات `stdlib/*.ف`، شغّل `python3 docs/documentation/generate-module-reference.py --lang ar` لتحديث فهرس التصريحات، ثم راجع شرح الرموز المتغيرة يدويًا. يستخرج المولّد التصريحات وقرائن قصيرة من أجسام الدوال؛ ولا يستطيع إثبات سلوكها. حدّث [التغطية](coverage.md) و[المسائل المفتوحة](unresolved.md) بالأدلة.

```sh
python3 -m pip install mkdocs pygments
python3 -m mkdocs build --strict -f mkdocs_ar.yml
python3 -m mkdocs serve -f mkdocs_ar.yml
python3 docs/documentation/validate.py --lang ar
```

ينشئ البناء الموقع في `site_ar/` محليًا فقط. افحص الصفحة الرئيسية والقواعد وإحدى الوحدات وكتلة برمجية تجمع العربية واللاتينية والأرقام في متصفح. انسخ الكتلة إلى ملف UTF-8 ونفذها للتحقق من ترتيب المحارف. عند تغيير السلوك، شغّل اختبارات المشروع بـ`ctest --test-dir build --output-on-failure`.

عند تغيير الصياغة، حدّث مرجعي اللغة ونسختي `language/grammar.ebnf` وقواعد الجذر وREADME. أبق أمثلة المتن في السطر نفسه ضمن `docs/documentation/validate.py` للتحقق من الصياغة والناتج في اللغتين باستخدام `--lang en` و`--lang ar`.
